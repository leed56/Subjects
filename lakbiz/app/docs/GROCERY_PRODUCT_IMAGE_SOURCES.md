# Grocery product image sources

This registry documents the locally bundled product photos used by the grocery catalogue. Matching code is in `src/components/sales/grocery-product-art.tsx`.

Verified branded photos require the product name (including pack size where known) to match; a barcode alone never selects a photo. Generic produce and bulk staple art is limited to whole-name matches. If neither an exact photo nor a trustworthy owner photo exists, the UI uses a neutral placeholder. Old category illustrations are ignored when they do not describe the product.

- Listing photos are bundled locally and fitted into a 512 × 512 white square while keeping the full product or package in frame. The package art itself is not modified.
- When no verified item photo matches, the product uses a neutral placeholder instead of borrowing unrelated product or category art. An owner can enter a public HTTPS image URL or an in-app image path in the product's image field; the editor previews it, and the saved owner image takes priority over bundled defaults.
- Product photos and trademarks remain the property of their respective owners. This source log records provenance; it does not grant a commercial reuse license. Confirm reuse rights with the brand or supplier before a public production release.
